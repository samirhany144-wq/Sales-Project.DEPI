# Superstore Sales Analysis

## Project Overview
This project is part of our DEPI Graduation Project.
It focuses on analyzing Superstore sales data to extract
business insights and support data-driven decisions.

## Project Objectives
- Understand the business and dataset.
- Identify key business questions.
- Define and analyze relevant KPIs.
- Develop an interactive Power BI dashboard.
- Present actionable business insights.
